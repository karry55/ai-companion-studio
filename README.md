# AI智能伴侣

基于 **Streamlit + DeepSeek API** 的个性化对话伴侣应用。

## 功能

- 自定义伴侣昵称、性格，AI完全代入角色聊天
- 流式对话，回复简短自然（像微信）
- 会话自动保存、历史记录查看、删除会话
- 左侧边栏管理会话，右侧主聊天区

## 技术

- Streamlit（界面）
- DeepSeek API（大模型）
- 本地 JSON 文件存储会话

## 运行

```bash
# 设置 API 密钥
export DEEPSEEK_API_KEY="your_key"

# 安装依赖
pip install streamlit openai

# 启动
streamlit run app.py
```


## 版本迭代记录

### 03_ai_partner01.py - 项目初始基础版本

实现 AI 聊天核心功能：接入 DeepSeek 大模型，完成基础的用户提问、AI 回答交互，支持单轮对话，搭建了最基础的项目框架。

---

### 04_ai_partner02.py - 功能优化版本

修复代码错误，升级为流式输出效果，AI 回复可以逐字实时显示，同时支持多轮上下文对话，交互体验大幅提升。

---

### 05_ai_partner03.py - 个性化增强版本

新增侧边栏配置功能，支持自定义 AI 伴侣的昵称、性格特点，让 AI 回复更贴合设定，丰富了交互的个性化。

---

### 06_ai_partner04.py - 完整最终版本

新增会话管理功能，支持历史对话的新建、保存、加载和删除，所有会话自动本地持久化，实现了功能完善、体验完整的 AI 伴侣系统。
