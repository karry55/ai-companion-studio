# AI智能伴侣

基于 **Streamlit + DeepSeek API** 的个性化对话伴侣应用。

## 功能

- 自定义伴侣昵称、性格，AI完全代入角色聊天
- 流式对话，回复简短自然（像微信）
- 会话自动保存、历史记录查看、删除会话
- 左侧边栏管理会话，右侧主聊天区

## 技术

- Streamlit（界面）
- DeepSeek API（大模型）
- 本地 JSON 文件存储会话

## 运行

```bash
# 设置 API 密钥
export DEEPSEEK_API_KEY="your_key"

# 安装依赖
pip install streamlit openai

# 启动
streamlit run app.py
```
